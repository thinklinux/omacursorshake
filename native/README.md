# omacursorshake (Hyprland plugin)

Shake-only compositor plugin, vendored from
[hypr-dynamic-cursors](https://github.com/VirtCode/hypr-dynamic-cursors)
commit `5a224284872208b5324759d535d65061043725de` (Hyprland 0.56.2).

Tilt, rotate, stretch, and shape rules are removed. Magnification on shake
and the hyprcursor high-resolution path are kept.
